# Content workflow

| Stage | Input | Output | Gate |
|---|---|---|---|
| Intake | Creator idea or permitted asset | Project and provenance | Rights basis required for source media |
| Intelligence | Topic and source metadata | Trend/context report | Confidence and attribution |
| Script | Brief and analysis | Localized script draft | Human script approval |
| Production | Approved script | Narration, captions, edit plan | Asset and voice permissions |
| Render | Versioned edit plan | Video and validation report | Automated media validation |
| Final review | Render and metadata | Approved package | Human final approval |
| Publish | Approved package | Platform post reference | Official platform API only |
| Measure | Platform metrics | Performance snapshot | Respect API permissions and retention |

Jobs preserve successful artifacts on failure. Idempotency keys prevent duplicate artifacts and external posts.
